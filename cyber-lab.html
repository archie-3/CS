Lesson 3 · Binary: the secret language
Binary Lab

      
Computers only understand 1 (on) and 0 (off). Each 1 or 0 is a bit.


    
1
Binary cards

      
Click a card to turn it on (1) or off (0). Add up the cards that are on. Make each target number. 4 bits are called a nibble.

      

      
Binary: 0000Number: 0

      

      

    


    
2
Your initials in binary

      
Every letter has a number code. A = 65, B = 66 … The computer stores that number in 8 bits (1 byte).

      

      
LetterNumberBinary (8 bits)

    


    
3
The hidden picture

      
Each row of the picture is stored as binary. 1 = black square, 0 = white square. Click squares to colour the picture, then press Check.

      

      

      

    


    
4
The magic trick (parity)

      
Step 1: Add squares in the last row and column so that every row and column has an even number of black squares (0, 2, 4…).

      
Step 2: Press Flip one. The computer secretly flips one square. Can you find it?

      

      

      

      
This is how computers check for errors when data is sent: an extra parity bit shows if something changed.

Lesson 7 · Keep it safe: defences
Password Lab

      
Never type a real password here. Make up practice ones. Nothing you type is saved or sent anywhere.


    
1
How long to crack it?

      
A hacker's computer can guess about 10 billion passwords every second. Type a practice password:

      
      

      
Time to crack: instantly

      

      
This is a rough estimate. Real hackers also try lists of common words and names, so choose words that are random, not your favourite things.

    


    
2
Three random words

      
UK cyber experts (the NCSC) say: join three random words. Easy to remember, hard to guess. Read the NCSC advice.
