Number Guessing Game

A guessing game's hints are unreliable — it sometimes tells you "too low" when your guess was too high.

Instructions
Run the program a few times and pay close attention to the hints. Try guessing well below the secret number, then well above it, and watch what happens each time. You should notice the hints aren't behaving sensibly — guessing too low gives you two hints at once, and guessing too high gives you no hint at all. There are two if statements checking the guess against the secret number — look closely at the comparison operators (< and >) used in each one.
number-guessing-game.py 
import random

secret_number = random.randint(1, 50)
guess = 0

while guess != secret_number:
    guess = int(input("Guess a number between 1 and 50: "))
    if guess < secret_number:
        print("Too low!")
    if guess < secret_number:
        print("Too high!")

print("Well done, you guessed it!")
Once it's working, try this
  • Add a counter that keeps track of how many guesses the player took, and print it once they win.
  • Limit the player to a maximum of 6 guesses — if they run out, print "Game over!" and reveal the correct number.
