Palindrome Checker

A palindrome checker says every word is a palindrome, even ones that clearly aren't.

Instructions
A palindrome is a word that reads the same forwards and backwards (like "level" or "madam"). Run this program with an obvious non-palindrome, like "python" — it will still claim it's a palindrome, which is wrong. The bug is in how the word is reversed: look up how Python's string slicing works with a step value of -1 versus a step value of 1, and fix the line that's supposed to reverse the word.
palindrome-checker.py 
# Checks whether a word is a palindrome (reads the same forwards and backwards)
word = input("Enter a word: ")
reversed_word = word[::1]

if word == reversed_word:
    print(word, "is a palindrome!")
else:
    print(word, "is not a palindrome.")
Once it's working, try this
  • Make the check ignore uppercase/lowercase differences, so "Level" and "level" both count as palindromes.
  • Put the check in a loop so the user can keep entering words, stopping only when they type "quit".
