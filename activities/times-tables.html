Times Table Generator

A times table prints, but it's missing one row it should have.

Instructions
Run the program and choose a number. It prints a times table for that number — but compare it to the real times table (check on paper or in your head for a number you know well, like 5). One row is missing from the end. Look at the range() the loop uses and work out why it stops one row early, then fix it.
times-tables.py 
# Prints the times table for a chosen number
number = int(input("Which times table would you like? "))

for i in range(1, 10):
    print(number, "x", i, "=", number * i)
Once it's working, try this
  • Let the user also choose how many rows to print (e.g. up to 20), instead of it always stopping at a fixed number.
  • Line the output up neatly in columns, e.g. using f-strings with fixed widths, so the equals signs all line up.
Debug it. Extend it. Make it yours, then run it in Thonny.
