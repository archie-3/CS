Ukraine Flag

A two-stripe flag is drawn, but the second stripe lands in the wrong place.

Instructions
Run the program. It should draw two horizontal stripes stacked on top of each other — blue above yellow, matching the real Ukrainian flag — but something's wrong with where the turtle draws the second rectangle. Read through the code and figure out where the turtle actually is after it finishes drawing the first (blue) rectangle.
