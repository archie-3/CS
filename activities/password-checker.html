Password Strength Checker

A password checker calls short passwords "strong" when it shouldn't.

Instructions
This program should only call a password "Strong" if it is at least 8 characters long AND contains at least one digit — both conditions need to be true. Run it and test it with a few different passwords: something short with a number in it (like "cat1"), something long with no number, and something that meets both rules. You should be able to find an input that gets called "Strong" when it clearly shouldn't be. Look closely at the condition in the if statement to find the mistake.
password-checker.py 
# Checks if a password is strong enough (needs 8+ characters and at least one digit)
password = input("Enter a new password: ")
has_digit = False

for character in password:
    if character.isdigit():
        has_digit = True

if len(password) >= 8 or has_digit:
    print("Strong password!")
else:
    print("Weak password - make it at least 8 characters long and include a number.")
Once it's working, try this
  • Also require at least one uppercase letter before a password counts as strong.
  • Instead of just Strong/Weak, give the password a score out of 3 based on how many of the criteria (length, digit, uppercase) it actually meets.
