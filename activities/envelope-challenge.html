The Envelope Challenge

Trace over a background outline image to complete a classic pen-tracing puzzle.

Instructions
This is the classic Envelope Challenge (from 101computing.net/the-envelope-challenge/). A faint envelope outline is shown behind the turtle's starting path — your job is to continue the pen.goto() calls so the turtle traces the rest of the envelope outline exactly, without lifting the pen (penup/pendown) at the wrong moment. Look at the background image carefully to figure out the coordinates of each corner.
This activity uses a background image. Download envelopebg.png and save it in the same folder as your envelope-challenge.py file — the code loads it by filename, so they need to sit side by side.
envelope-challenge.py 
#The Envelope Challenge - www.101computing.net/the-envelope-challenge/
import turtle
screen = turtle.Screen()

# this assures that the size of the screen will always be 400x400 ...
screen.setup(400, 400)
screen.bgpic("envelopebg.png")

pen = turtle.Turtle()
pen.shape("arrow")
pen.speed(100)
pen.color("#810081")
pen.pensize(6)
pen.penup()

pen.goto(-150,-150)
pen.pendown()
pen.goto(-150,75)
pen.goto(150,75)
