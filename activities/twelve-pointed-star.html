For Loop — 12 Pointed Star

A working 6-pointed star loop is provided — work out what to change to get 12 points.

Instructions
Run the program and watch it draw a 6-pointed star using a for loop. Read the loop carefully: it repeats a forward-and-back movement a certain number of times, turning a bit each time. Can you work out which two numbers control how many points the star has, and change them to make a 12 pointed star instead? Try changing the pensize too and see what happens.
twelve-pointed-star.py 
import turtle
import time


turtle.pencolor("light blue")
turtle.pensize (10)  #What happens if you change the number?


for i in range(6): #repeat the code below the number in the bracket 
  turtle.forward(100)
  turtle.backward(100)
  turtle.left(30)
time.sleep(5) # gets the program to wait 5 secs

# Can you finish this program to make a 12 pointed star?
