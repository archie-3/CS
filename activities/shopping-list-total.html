Shopping List Total

A shopping list total and average come out wrong — the loop isn't adding things up correctly.

Instructions
This program should add up all 5 prices in the list to get a total, then divide by 5 to get the average. Run it and work out the total yourself by hand (or on a calculator) to check it — the program's answer will be wrong. Look at what happens inside the for loop each time it runs, and think about the difference between replacing a value and adding to it.
shopping-list-total.py 
# Calculates the total and average price of items in a shopping list
prices = [2.50, 4.00, 1.20, 6.75, 3.30]

total = 0
for price in prices:
    total = price

average = total / len(prices)

print("Total spent: £" + str(total))
print("Average price: £" + str(average))
Once it's working, try this
  • Print out the most expensive item in the list, using max().
  • Ask the user to enter one more price with input(), add it to the list, and include it in the total and average.
