Germany Flag

The flag outline and fill colours are set up — fill in the drawing code for each stripe.

Instructions
Write a program to draw a flag that is 250 turtle steps wide, and 80 turtle steps high. The top third should be 'black'. The middle third should be 'red'. The bottom third should be 'yellow'. Each stripe already has begin_fill()/end_fill() and a fillcolor() set — you need to add the forward()/right() movements between them to actually draw each rectangle, and move the turtle into position for the next stripe before it starts filling.
germany-flag.py 
'''Write a program to draw a flag that is 250 turtle steps wide, and 80 turtle steps high.
The top third should be 'black'.
The middle third should be 'red'.
The bottom third should be 'yellow'.'''


import turtle
import time
turtle.penup()
turtle.goto(-100,150)
turtle.pendown()

#Creates the black part of the flag
turtle. fillcolor("black")
turtle.begin_fill() #Start filling in the shape

turtle.end_fill() #Stop filling in the shape
time.sleep(5) #Waits for 5 seconds

#red part of the flag

turtle. fillcolor("red")
turtle.begin_fill()  #Start filling in the shape

turtle.end_fill() #Stop filling in the shape
time.sleep(5) #waits for 5 seconds

#Can you create the yellow part of the flag?
turtle. fillcolor("yellow")
turtle.begin_fill()  #Start filling in the shape

turtle.end_fill() #Stop filling in the shape
time.sleep(5) #waits for 5 seconds
