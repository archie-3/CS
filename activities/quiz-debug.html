Debug the Quiz Program

A two-question quiz has a couple of mistakes stopping it from running at all.

Instructions
This quiz program won't run yet — it has two separate mistakes in it. Open it in Thonny and press Run. Python will stop at the first problem it finds and print an error message with a line number — read that message carefully, it tells you what kind of mistake it is. Fix that one issue, run again, and you'll likely hit a second error further down. Keep fixing and re-running until both quiz questions work correctly.
quiz-debug.py 
# A simple quiz program
print("Welcome to the quiz!")

answer1 = input("What does CPU stand for? ")
if answer1 == "Central Processing Unit"
    print("Correct!")
else:
    print("Wrong! The answer is Central Processing Unit.")

answer2 = input("How many bits are in a byte? ")
if answer2 = "8":
    print("Correct!")
else:
    print("Wrong! The answer is 8.")  # Quiz ends here
Once it's debugged — extension tasks

Work through these in order — each tier builds on the last.

Bronze
  • Add a third question to the quiz. Choose your own topic.
  • Run the program and check all three answers work correctly.
  • Print a message at the end: "Thank you for playing!"
Silver
  • Add a score counter. Start at 0.
  • Each correct answer adds 1 to the score.
  • Print at the end: "You scored X out of 3."
  • Hint: use score += 1 for each correct answer.
Gold
  • Make answers case-insensitive (try .lower()).
  • Add input validation — if user types nothing, ask again.
  • Add a 4th question where the answer is a number. Handle int() safely.
  • ⭐ Print 'Perfect score!' only if they got all 4 correct.
Debug it. Extend it. Make it yours, then run it in Thonny.
