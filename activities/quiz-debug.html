Debug the Quiz Program

A two-question quiz has a couple of mistakes stopping it from running at all.

Instructions
This quiz program won't run yet — it has two separate mistakes in it. Open it in Thonny and press Run. Python will stop at the first problem it finds and print an error message with a line number — read that message carefully, it tells you what kind of mistake it is. Fix that one issue, run again, and you'll likely hit a second error further down. Keep fixing and re-running until both quiz questions work correctly. Once it runs cleanly, try extending it: add a third question of your own, and keep score of how many the player gets right.
quiz-debug.py 
# A simple quiz program
print("Welcome to the quiz!")

answer1 = input("What does CPU stand for? ")
if answer1 == "Central Processing Unit"
    print("Correct!")
else:
    print("Wrong! The answer is Central Processing Unit.")

answer2 = input("How many bits are in a byte? ")
if answer2 = "8":
    print("Correct!")
else:
    print("Wrong! The answer is 8.")  # Quiz ends here
