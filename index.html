Python activities to copy into Thonny and take apart.

Each activity below starts out slightly wrong or slightly incomplete. Copy or download the code, open it in Thonny, and get it working — then push it further.

How to use these with Thonny
  1. Don't have Thonny yet? Install it free from thonny.org.
  2. Open an activity below, then either click Copy code and paste it into a new Thonny file, or click Download .py and open that file in Thonny directly.
  3. In Thonny, save the file into your own folder first (File → Save As) so you're editing your own copy, not the original.
  4. Press F5 (or the green Run arrow) to run it, read the instructions on the page, and start debugging or extending.
